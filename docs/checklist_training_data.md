Training Data Checklist
=======================

Introduction
------------

As the City of Amsterdam, we would like to know that training data of used models:
* has been disclosed in line with our own value for **transparency** [binary]
* does not contain **personal** / proprietary data / violate **copy rights** [impossible? checklist -> yes/no / ]
* has been **collected and annotated responsibly** [open? impossible?]
* is **inclusive** and represents the **diversity** in society [impossible?]
* contains content supporting **our own values** [impossible?]
* the amount of **Dutch** in it [binary? emoji with Dutch flag? %?]


Checklist
---------
1. Check if training data is publicly available
2. Check whether the model has been explicitly trained on Dutch (and if possible what % of data)
3. Check if training data contains personal or copy-right data ??? 
    * HOW?
    * Proposal:
        - Which datasets / data sources (training data) were used to train the model?
        - Does the training data potentially contain personal data (article 4(1) GDPR)? 
        - If the supplier used personal data to train the model, does the supplier provide documentation / information in which it states that the processing of personal data was legitimate pursuant to the GDPR? If so, this documentation / information needs to be verified by a privacy officer of the municipality before proceeding.
        - If the supplier doesn’t provide documentation / information regarding the legitimacy of the processing, there are a few options:
            * Ask the supplier for additional information regarding potential personal data in the training data and any mitigating measures it has taken prevent personal data in training data. The response needs to be verified by a privacy officer of the municipality before proceeding.
            * Research publicly available information to assess whether it is likely that the supplier used personal data to train its models. For example, if it is clear/most likely/obvious that a supplier has used scrapping – techniques to gather data for training purposes, it is very likely that any further processing of this data was not legitimate. Therefore, it is very likely that the finished product, the LMM, was the result of illegitimate processing of personal data of unknown data subject.
